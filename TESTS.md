# Проверки PrideMessenger

Схема миграций `202610310001`–`202610310005` применена к **отдельному** проекту PrideMessenger. Каждая миграция сначала прошла синтаксическую проверку и пробный запуск с откатом. Настройки Auth направляют email-подтверждение на `https://iamskoup.github.io/pride/`; подтверждение обязательно.

Сквозной API-тест `checks/supabase_live_check.py` создаёт три временных аккаунта, проверяет 34 сценария и удаляет тестовые данные. Проверены создание и скрытие личного и группового чата, авторизация участников, идемпотентная отправка, редактирование, приватное вложение, запрет удаления сообщения до удаления файла, изоляция Claws и подписки, вступление в прайд и права текстового канала. Последний прогон: **34/34 прошли**, тестовые аккаунты и объекты удалены.

Отдельная проверка через настоящий браузерный Supabase SDK подтвердила вход временного пользователя, загрузку профиля и открытие раздела Pc; аккаунт удалён. DOM-проверка в jsdom подтвердила интерактивную отправку в локальном деморежиме, работу `file://` без доступа к localStorage, экран Auth, рабочую оболочку, раздел Pc и настройки. Проверки `node --check` прошли для обоих клиентских скриптов. Основные текстовые пары новой палитры имеют контраст от 5.1:1 до 16.4:1; в CSS не осталось выраженных зелёных оттенков.

**Не подтверждено** отдельным браузерным тестом: фактическая доставка Realtime через WebSocket между двумя открытыми вкладками, доставка писем, мобильные размеры 320/375/768 px, поведение экранной клавиатуры, PWA offline после установки. Headless Chromium в облачной среде зависал до создания скриншота. Проверка оплаты Pc невозможна без merchant API PrideCoin; платные действия отключены.
