# PrideMessenger: архитектура новой версии

Приложение развёртывается из `next/` как статический сайт GitHub Pages по `/pride/`. В продакшене оно подключается только к отдельному проекту Supabase **PrideMessenger** (`gnvihjeqheupzgcwcefv`, организация Pride). Firebase, Cloudflare Worker, базы PrideCoin и Kapani в новом клиенте не используются. Проект на бесплатном плане; платные ресурсы не подключались. Публичный ключ Supabase в `next/config.js` предназначен для браузера; секретные ключи остаются только на серверной стороне.

При открытии `index.html` через `file://` или с `?demo=1` запускается отдельный локальный деморежим. Он не создаёт настоящие аккаунты и не синхронизирует данные. На HTTPS работает Supabase Auth с подтверждением почты, PostgreSQL, RLS, Storage и Realtime. Путь подтверждения почты разрешён для `https://iamskoup.github.io/pride/`.

Профиль с уникальным без учёта регистра username создаётся триггером Auth. Личные и групповые беседы хранят членство отдельно от сообщений; все операции записи проходят функции с проверкой `auth.uid()`. Чтение ограничено RLS. Сообщения имеют клиентский UUID, чтобы повтор отправки не дублировал запись. В клиенте загружаются последние 50 сообщений, локальный черновик сохраняется по пользователю. Подписка Realtime обновляет открытый чат и канал.

Вложения находятся в приватном бакете `pm-attachments` с лимитом 10 МБ. Путь включает ID чата и владельца; участники чата могут скачивать файл, загружать и удалять его может только владелец. Сообщение с вложением не удаляется сервером до удаления объекта Storage и записи привязки. Прайды сейчас поддерживают открытое вступление и текстовый канал; роли и приватные каналы ещё не реализованы.

Claws и подписки хранятся в отдельной серверной схеме только для чтения владельцем. Клиент не имеет права менять остаток или план. Цены представлены в Pc: Savanna 0, Cheetah 149, Leopard 349, Lion 699 Pc в месяц. Кошелёк PrideCoin: https://iamskoup.github.io/pc/ . Переход по ссылке не доказывает платёж. Для покупки нужен ограниченный merchant API PrideCoin с созданием счёта, подтверждением списания в кошельке, подписанным webhook, проверкой суммы и SKU, идемпотентной выдачей подписки и обработкой возврата. Пока этого API нет, покупка в UI отключена. Ключ управления Supabase и ключи PrideCoin не должны попадать в браузер.

Перед расширением до функций мастер-промпта необходимо проектировать отдельные политики доступа для приватных прайдов и каналов, модерации, голосовых комнат, подарков, звонков и расширенного профиля. Не следует считать их работающими по наличию экранов или таблиц.
