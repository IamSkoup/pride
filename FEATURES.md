# PrideMessenger — текущая версия

| Область | Реализовано | Ещё требуется |
| --- | --- | --- |
| Инфраструктура | Отдельный проект Supabase `gnvihjeqheupzgcwcefv`, Auth, PostgreSQL, RLS, приватный Storage, публикации Realtime | Нагрузочные проверки и мониторинг |
| Аккаунты | Email/пароль, обязательное подтверждение почты, восстановление и изменение пароля, сессия, профиль, выход; встроенная почта Supabase ограничена 2 письмами/час без своего SMTP | Удаление аккаунта, OAuth, блокировки, приватность и расширенный профиль |
| Переписка | Личные и групповые чаты, поиск по точному username, история последних 50 сообщений, отправка с идемпотентностью, редактирование и удаление своих сообщений, локальные черновики, подписка Realtime | Пагинация, реакции, поиск по сообщениям, прочтение/доставка, управление группами |
| Вложения | Приватный бакет, фото/GIF/PDF/текст/WebM до 10 МБ, загрузка/скачивание только участниками, защищённое удаление | Превью, прогресс, голосовая запись, обработка медиа и очистка после удаления аккаунта |
| Прайды | Создание открытого прайда, вступление, текстовый канал, сообщения с RLS и Realtime | Приватные прайды, роли, модерация, голосовые каналы, форумы, приглашения |
| Pc и Claws | Каталог 0/149/349/699 Pc, ссылка на кошелёк PrideCoin, Claws и подписка отображаются из серверной базы только для владельца | Merchant API PrideCoin, подтверждённые покупки, выдача Claws, подарки и возвраты |
| Оформление | Чёрно-оранжевая тема по умолчанию, альтернативная светлая, оригинальное изображение саванны, адаптивный интерфейс и PWA, интерактивный `file://` деморежим | Полная английская локализация и проверка на физических мобильных устройствах |

Функции из большого мастер-промпта, не указанные как реализованные, не выдаются за готовые. Платные кнопки заблокированы до появления безопасного подтверждения списания Pc. Действующая реализация PrideCoin не имеет ограниченного merchant API, поэтому переход в кошелёк не может активировать подписку.
