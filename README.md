# PrideMessenger

Новая статическая версия находится в [`next/`](next/). Она использует отдельный Supabase-проект PrideMessenger для аккаунтов, сообщений, приватных вложений и текстовых каналов прайдов. Интерфейс оформлен в чёрно-оранжевых цветах с оригинальным фоном саванны. Список готовых и отсутствующих функций — в [`FEATURES.md`](FEATURES.md), результаты проверок — в [`TESTS.md`](TESTS.md).

Для локального демо откройте `next/index.html` двойным щелчком. Демо работает без аккаунта и хранит данные в браузере, если доступно локальное хранилище. Для проверки настоящего Supabase-клиента запустите `python -m http.server 8000 --directory next` и откройте `http://localhost:8000/`; для регистрации по email используйте опубликованный HTTPS-адрес, где настроен redirect подтверждения. Сборка и npm для клиента не нужны.

Публичные URL и publishable key лежат в `next/config.js`. Секретные ключи в репозиторий добавлять нельзя. Схема БД версионирована в `supabase/migrations/`; миграции `001`–`005` уже применены к отдельному проекту. Повторно запускать их в этом проекте нельзя. API-тест можно повторить командой `python checks/supabase_live_check.py` при наличии настроенного `SUPABASE_ACCESS_TOKEN`; он создаёт и удаляет временные тестовые аккаунты и файлы. Не запускайте его против другого проекта.

GitHub Actions публикует содержимое `next/` в GitHub Pages при обновлении `main`. Покупки за Pc выключены до появления проверяемой merchant-интеграции с PrideCoin; ссылка на кошелёк не активирует подписку.
